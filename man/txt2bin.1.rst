==============
txt2bin
==============

--------------------------------------------------------
Text To Binary
--------------------------------------------------------
:Version: txt2bin |version|
:Manual section: 1

Synopsis
========

txt2bin *[options]* *out_file* *[in_txt_files]*

Description
===========

Converts text to binary.

Options
========

-f encoding_format      Encoding format ('base64').

-h                      Display help.
-c                      Enable color output
-v                      Enable verbose output
